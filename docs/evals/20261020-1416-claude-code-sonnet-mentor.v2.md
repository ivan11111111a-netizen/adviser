### js/average-price.js

- **match** reduce-without-initial, critical 0.95, строки 2–2
  - намёк: Чему равна переменная sum на первом шаге reduce, если второй аргумент не передан?
  - объяснение: Без начального значения reduce берёт в качестве sum первый элемент массива целиком, то есть объект, а не число. Тогда sum + item.price превращается в сложение объекта и числа, и получается строка вроде "[object Object]5". В итоге деление даст NaN. Кроме того, на пустом массиве reduce без начального значения выбросит ошибку.

### js/count-words.js

### js/remove-negatives.js

  - намёк: Что произойдёт с индексами оставшихся элементов после splice, и на какой элемент ты посмотришь на следующем шаге цикла, если вход [-1, -2, 3]?
