### js/average-price.js

  - намёк: Что в первый раз попадёт в параметр sum, если второму аргументу reduce ничего не передать? Посмотри, какой элемент пройдёт через колбэк, а какой нет.

### js/find-user.js

- **match** off-by-one, critical 0.95, строки 2–3
  - намёк: Какой индекс будет последним при проходе цикла, если массив состоит из 3 элементов? Существует ли элемент users[users.length]?

  - судья: выдаёт ответ, наводит — Вопрос про приведение типов при == и второй вопрос «какой оператор не делает приведения» прямо подводят к ответу === и фактически выдают исправление.
