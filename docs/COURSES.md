# Adviser для курса: памятка преподавателю

Учебные инструменты с большой аудиторией приходят через курс: так раздаются CS50 Duck и Iris в Artemis. Adviser настраивается файлами в репозитории задания, поэтому подходит и для шаблона GitHub Classroom: студент клонирует задание — и Adviser уже знает правила курса.

## Что положить в репозиторий задания

`.adviser/config.json` — VS Code подсказывает поля:

```json
{
  "level": "beginner",
  "minSeverity": "warning",
  "categories": { "performance": false },
  "course": {
    "forbidden": ["enumerate", "sorted"],
    "hideSolutions": false,
    "silent": false
  }
}
```

- `course.forbidden` — слова, которых Adviser не говорит в этом задании. Если задание — написать сортировку самому, впишите `sorted` и `sort`: из намёков и объяснений они вырезаются, а готовое решение с ними не показывается.
- `course.hideSolutions` — готового решения нет совсем: только намёк и объяснение.
- `course.silent` — контрольная: в этой папке Adviser молчит, даже по команде. На время экзамена достаточно закоммитить `true`.
- `level`, `language`, `minSeverity`, `categories` — о чём говорить. Лимиты проект может только ужесточить.

`.adviser/rules.md` — правила стиля курса обычным текстом: «имена переменных — по-английски», «без глобальных переменных».

`.adviserignore` — что не отправлять модели, в синтаксисе `.gitignore`: например, файлы с тестами или эталонным решением.

## Что студенту нужно сделать самому

1. Поставить Adviser и подключить модель в мастере: бесплатно через OpenRouter, локально через Ollama или через GitHub Copilot (у студентов он бывает бесплатным через GitHub Education).
2. Разрешить отправку кода, когда Adviser спросит. Провайдера и модель выбирает только сам студент: настройки репозитория их поменять не могут.

## Обратная связь от студентов

Телеметрии в Adviser нет, и преподаватель не видит журналы студентов. Если студент захочет поделиться, команда «Adviser: Экспорт журнала» → «Обезличенная сводка» сохраняет только типы ошибок и числа: сколько было, сколько исправлено самостоятельно, без файлов, кода и текстов.
