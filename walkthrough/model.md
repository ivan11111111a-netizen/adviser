# Кто будет разбирать код

Adviser отправляет функцию, которую ты изменил, языковой модели и показывает её разбор. Пути к модели — от бесплатного к платному.

## 1. Бесплатно: OpenRouter

Модели с суффиксом `:free` ничего не стоят: до 50 запросов в сутки, этого хватает примерно на полтора часа учёбы. Нужна только регистрация и ключ.

Важно: у бесплатных моделей провайдер может использовать запросы для обучения своих моделей. Для учебных проектов это обычно приемлемо, для рабочего кода — нет.

## Через GitHub Copilot

Ключ не нужен: Adviser берёт модели Copilot через VS Code. В свежем VS Code Copilot уже встроен — достаточно войти в GitHub, кнопка входа появится сама. Студентам Copilot бывает бесплатным через GitHub Education. У бесплатного тарифа Copilot небольшой месячный лимит: в режиме «Наставник» он кончится быстро. Запросы расходуют лимиты твоего плана Copilot. В Cursor и Windsurf этот путь не работает.

## 2. Локально: Ollama

Бесплатно, и код не покидает компьютер. Нужна видеокарта: модели вроде `qwen2.5-coder:7b` работают на 8 ГБ видеопамяти, `qwen2.5-coder:14b` и `gpt-oss:20b` — на 16 ГБ. На слабом компьютере этот путь не подойдёт.

## 3. Свой ключ

Любой OpenAI-совместимый провайдер: OpenAI, DeepSeek, Groq, LM Studio и другие. Платно, но обычно точнее. Расход и лимиты в долларах — настройки `adviser.budget.*`.

Ключ хранится в защищённом хранилище VS Code, а не в настройках.
