# What a review looks like

An issue arrives in steps:

1. **Hint**: a question in the underline. Think about it yourself first.
2. **Explanation**: the "Explain" button in the hover: why this is a mistake.
3. **Solution**: the "Show solution" button. Press it when you could not get there yourself.

While you see only the hint, you can press "Check me" and explain the mistake in your own words: Adviser will tell you if you are right.

If the code is insecure, there is no hint: the explanation comes right away.

In the Mentor mode Adviser reviews on its own: when you save the file, leave a changed function or stop typing for 30 seconds. Modes, Do Not Disturb and the log: click Adviser in the status bar.

An issue has a light bulb: "got it", "I disagree", "stop showing".
