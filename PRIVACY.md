# Приватность Adviser

Коротко:

- Adviser отправляет код только той модели, которую ты сам выбрал в настройках. Своих серверов у Adviser нет.
- Телеметрии нет: разработчику Adviser не уходит ничего — ни статистика, ни ошибки, ни код.
- Журнал ошибок, отчёты и расход хранятся только на твоём компьютере.

## Куда уходит код

Только на адрес из настройки `adviser.baseUrl` выбранного провайдера (по умолчанию OpenRouter). Провайдер, адрес и модель берутся только из твоих пользовательских настроек: настройки проекта (`.vscode/settings.json`, `.adviser/config.json`) их поменять не могут, иначе чужой репозиторий мог бы увести код и ключ на свой сервер.

Перед первой отправкой на новый сервер Adviser показывает, куда и что уйдёт, и спрашивает разрешение. Для серверов на этом компьютере (Ollama, LM Studio на `localhost`) не спрашивает: код не покидает машину. Отозвать разрешения — команда «Adviser: Отозвать разрешение на отправку кода».

Если исчерпан лимит в долларах (`adviser.budget.*`) и задана запасная модель (`adviser.budget.fallbackModel`), код уходит ей. Запасная модель может быть только на этом компьютере (`localhost`), поэтому в сеть код при этом не уходит.

**Бесплатные модели.** У бесплатных моделей (на OpenRouter — с суффиксом `:free`) провайдер может использовать запросы для обучения своих моделей. Для учебных проектов это обычно приемлемо, для рабочего кода — нет. Условия задаёт провайдер, читай их у него.

## Когда уходит

- По команде «Adviser: Разобрать эту функцию».
- В режимах «Наставник» и «Ревьюер» — сам, когда ты меняешь функцию: при сохранении, уходе из неё и (в «Наставнике») после паузы в наборе. Разбираются только функции, которые ты правил.
- В режиме «Вручную» — только по команде. «Не беспокоить» в статус-баре останавливает автоматические разборы на 30 минут или час.
- В недоверенных папках (Workspace Trust) Adviser выключен целиком.

## Что уходит модели

При разборе, если ответа нет в кэше:

- код разбираемой функции или выделенных строк — с номерами строк;
- окружение функции: что нашли в этих строках линтер и компилятор, импорты и первые строки соседних функций и классов этого файла, первые строки функций из других файлов проекта, которые функция вызывает, имена и версии зависимостей из `package.json` или `requirements.txt`;
- правила стиля проекта из `.adviser/rules.md`, а если в `.adviser/config.json` включено `readAgentFiles` — ещё AGENTS.md, CLAUDE.md, `.cursorrules` и `.github/copilot-instructions.md`;
- до пяти самых частых типов твоих ошибок за три недели — только тип и его название, без кода;
- язык программирования, твой уровень и язык советов.

## Что не уходит

- Файлы `.env*` — никогда, даже по команде.
- Файлы из `.adviserignore` (синтаксис как у `.gitignore`) и из `ignore` в `.adviser/config.json`. Если в этих файлах ошибка, Adviser не разбирает ничего в этой папке, пока её не исправят: опечатка не должна молча открыть то, что ты закрыл.
- В окружение не берутся первые строки констант: в значении бывает ключ.
- Ключи и пароли в отправляемом тексте заменяются меткой `<секрет скрыт>`: ключи известных сервисов (AWS, GitHub, OpenAI, Anthropic, OpenRouter, Stripe, Slack, Google, JWT), значения переменных с именами вроде `password`, `secret`, `token`, `api_key`, логин и пароль в адресах, длинные случайные строки. Это страховка, а не гарантия: маскировка находит не всё, поэтому не держи настоящие ключи в коде.
- Журнал ошибок, отчёты, расход токенов, твои ответы «понял» и «не согласен».

## Что хранится на компьютере

- **Ключ API** — в защищённом хранилище VS Code (SecretStorage, оно опирается на хранилище паролей ОС), не в настройках.
- **Журнал ошибок** — `journal.json` в папке данных расширения (`globalStorage`): тип ошибки, файл и строка, текст первой ступени (намёк или объяснение), время, до какой ступени ты дошёл, исправлено ли, твой ответ. Там же `report.md` — последний недельный отчёт.
- **Расход токенов по дням, разрешения на отправку, «Не беспокоить», отметка о показанном мастере** — во внутреннем хранилище VS Code (`globalState`).
- **Кэш ответов** — только в памяти, до перезапуска окна.
- **Лог** (Output → Adviser) — пути файлов, краткие итоги разборов и число скрытых секретов, без самого кода. Пишется только локально.

Как удалить: ключ — командой «Adviser: Задать API-ключ» с пустым значением; журнал и отчёт — вместе с папкой расширения в `globalStorage` VS Code (на Windows это `%APPDATA%\Code\User\globalStorage`).
